## 🌐 GitHub Pages Live Hosting

This boutique is configured for **GitHub Pages**:
- **Live URL**: `https://rehan9896.github.io/ch-perfume/`

### How to Enable GitHub Pages (1-Minute Setup):
1. Navigate to your repository on GitHub: [https://github.com/rehan9896/ch-perfume](https://github.com/rehan9896/ch-perfume)
2. Click **Settings** (top right tab) → Select **Pages** (in the left sidebar under *Code and automation*).
3. Under **Build and deployment** → **Source**:
   - Choose **GitHub Actions** (recommended — uses `.github/workflows/deploy.yml` for automatic deployment on every push).
   - *OR* choose **Deploy from a branch** → Branch: `main` → Folder: `/ (root)` → Click **Save**.
4. GitHub Pages will build and deploy the site in ~60 seconds.
